# 智能家居设备控制中心 (Smart Home Hub)

基于 C++ 面向对象思想设计的智能家居设备管理模拟系统。

综合运用封装、继承、多态、虚函数、运算符重载、友元、异常处理、文件持久化及 ANSI 终端美化等核心知识。

---

## 功能特性

| 功能 | 说明 |
| ------ | ------ |
| **多态设备管理** | 统一基类 `SmartDevice` 管理智能灯、空调、门锁，支持一键全开/全关 |
| **单独设备控制** | 按设备 ID 精确控制，支持开/关、亮度/温度/锁定等专属操作 |
| **场景模式联动** | 回家 / 睡眠 / 离家三种场景，通过 Lambda 批量调度设备 |
| **运算符重载** | `+` 添加设备，`<<` 输出详情，`++ / --` 调节亮度 |
| **友元日志系统** | `SystemLogger` 作为友元访问私有设备列表生成报告 |
| **异常安全** | 密码错误、温度越界等场景抛出自定义异常，程序不崩溃 |
| **配置持久化** | 设备状态自动保存至 `smart_home.cfg`，启动时自动恢复 |
| **交互式菜单** | 命令行彩色菜单，支持添加、删除、单控、场景、日志报告 |
| **安全输入** | 所有输入均做类型/范围/空值校验，防缓冲区残留 |
| **ANSI 美化** | 支持 WSL 终端真清屏、颜色高亮与 Emoji 图标 |

## 快速开始

### 环境要求

- C++14 及以上编译器
- 支持 `g++` 和 `make`
- 已在 WSL / Linux / macOS 终端环境验证

### 编译

进入项目目录后执行：

```bash
make
```

或手动编译：

```bash
g++ -std=c++14 -Wall -Iinclude src/main.cpp src/SmartDevice.cpp src/SmartHomeHub.cpp -o bin/smart_home
```

编译完成后：

- 中间文件在 `build/`
- 可执行文件在 `bin/smart_home`

### 运行

```bash
./bin/smart_home
```

程序启动时会自动加载当前目录下的 `smart_home.cfg`，若不存在则使用默认设备。

## 配置文件

设备状态保存到当前目录的 `smart_home.cfg`，格式如下：

```text
Light L001 客厅主灯 1 80
Light L002 书房灯 0 60
AC AC01 主卧空调 0 26
Lock LK01 大门门锁 1 0
```

字段含义：

| 列 | 说明 |
| ---- | ------ |
| 第 1 列 | 设备类型：`Light` / `AC` / `Lock` |
| 第 2 列 | 设备 ID |
| 第 3 列 | 设备名称 |
| 第 4 列 | 开关状态：`1` 开，`0` 关 |
| 第 5 列 | 附加值：灯光亮度 / 空调温度 / 门锁锁定状态 |

## 知识点映射

| 课程知识 | 代码体现 |
| ---------- | ---------- |
| **类与对象 / 封装** | 每个设备独立成类，私有属性 + 公有接口 |
| **构造 / 析构** | 设备对象生命周期管理，Hub 析构自动释放所有设备 |
| **初始化列表** | `const string deviceID` 必须在初始化列表赋值 |
| **虚析构函数** | `virtual ~SmartDevice()` 防止内存泄漏 |
| **纯虚函数 / 抽象类** | `turnOn() = 0` 等 |
| **继承** | `SmartLight : public SmartDevice` |
| **多态** | `vector<unique_ptr<SmartDevice>>` 统一管理不同设备 |
| **运算符重载** | `operator+`, `operator++`, `operator<<` |
| **友元** | `SystemLogger` 访问 `SmartHomeHub` 私有 `devices` |
| **异常处理** | `try-catch` 捕获 `DeviceException` / `SecurityException` |
| **文件流** | `ofstream` 保存 `smart_home.cfg` |
| **Lambda / std::function** | `sceneMode()` 批量操作设备 |
| **const / static** | 设备 ID 只读、在线设备总数统计 |
| **RAII** | `SmartHomeHub` 析构时统一 `delete` 所有设备 |
